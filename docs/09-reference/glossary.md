# Glossary

- **Combo model**: Named model sequence for fallback/strategy routing.
- **Connection**: Provider credential record in `providerConnections`.
- **Compatible node**: User-defined OpenAI/Anthropic-compatible backend endpoint.
- **RTK**: Request tool-result compression filters under `open-sse/rtk`.
- **Caveman mode**: terse prompt injection option for reduced verbosity.
- **CLI token**: machine-derived token accepted by middleware for local CLI access.
- **Request details**: persisted per-request debug record in `requestDetails` table.
- **Cloud sync scheduler**: periodic sync caller initialized at app startup.
